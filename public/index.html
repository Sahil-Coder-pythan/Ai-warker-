GitHub Token लगाओ

Classic Personal Access Token (repo scope). Token सिर्फ इस डिवाइस पर रहता है — दूसरे यूज़र को कभी नहीं दिखेगा।

Token कैसे बनाएँ?
  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate new token (classic)
  3. Scopes: repo (full control) चुनो
  4. Generate → कॉपी करके यहाँ paste करो

Repo चुनो

1️⃣ सारी फाइलें Delete

Repo की सारी फाइलें एक commit में wipe हो जाएँगी (force)।

2️⃣ ZIP Upload (नक्शे के हिसाब से)

ZIP चुनो + optional नक्शा (JSON)। नक्शा खाली छोड़ोगे तो ZIP का अपना structure लगेगा।

यह टूल बैकग्राउंड में GitHub API से काम करता है। Browser/mobile window नहीं खुलता। एक लिंक कई लोग चलाएँ तो भी एक-दूसरे की token/files कभी नहीं दिखतीं।
